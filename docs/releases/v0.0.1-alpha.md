# PL Creators Suite v0.0.1-alpha

## Status

Early alpha foundation build.

## Platform

- Linux AppImage

## Included

- Electron desktop shell
- Vite/React renderer
- Local project create/open flow
- Recent projects
- Project import/export using .plproj
- Native dialogs
- Native menus and shortcuts
- Window state persistence
- Hardened preload bridge baseline
- Plugin registry foundation
- Plugin manifest validation
- Plugin discovery from example plugins
- Plugin enable/disable state
- Feature flag foundation
- Local AI service stub
- Linux AppImage packaging

## Known limitations

- Plugins are discovered and tracked but not executed yet.
- Local AI is a stub and does not call a model runner yet.
- App icon is temporary.
- No auto-update system yet.
- Linux packaging only for now.
