# PL Creators Suite Public Beta 1.1 Validation

## Release Status

Public Beta 1.1 validation is substantially complete.

Linux development, automated validation, native project round-trip testing, recovery testing, compatibility baselining, performance baselining, RPC validation, and live application testing have passed.

Windows clean-build, packaging, upgrade, rollback, and final installer validation remain pending and must pass before Public Beta 1.1 is tagged or published.

## Release Goal

Public Beta 1.1 establishes a reproducible, measurable, data-safe baseline for continued development through Official Version 1.0.

## Known Limitations

Known v1.1 limitations include:

- Windows final validation remains pending
- Windows packaging remains pending
- v1.0 → v1.1 upgrade validation remains pending
- rollback verification remains pending
- uninstall/user-data-preservation verification remains pending
- all-slice canonical reference project remains pending
- renderer production bundle remains above the current Vite chunk-size warning threshold
- renderer engine systems remain largely in-process
- generalized worker/job infrastructure is not yet complete
- third-party extension process sandboxing is not yet complete
- full autosave/history/snapshot/recovery services belong to v1.2
- broad external-format interoperability is not certified by the v1.1 baseline

## Data-Loss Triage

No currently known tested project-format or import failure identified during v1.1 validation remains untriaged.

Any newly discovered data-loss issue is a Public Beta 1.1 release blocker until classified and addressed.

## Pending Public-Beta Release Gate

Before Public Beta 1.1 may be tagged and published:

1. Run clean Windows validation.
2. Verify Windows package generation and installer startup.
3. Exercise v1.0 → v1.1 upgrade.
4. Verify rollback behavior.
5. Verify uninstall does not unexpectedly destroy user project data.
6. Verify settings and extension state preservation.
7. Create and reopen the all-slice reference project.
8. Regenerate capability traceability and final validation evidence.
9. Build/checksum Linux and Windows release packages.
10. Tag the exact validated source state.

## Result

Current state: **release candidate pending Windows and upgrade/rollback validation**.

The Linux and project-safety baseline is validated and development may proceed into v1.2 shared-platform work while the remaining Public Beta 1.1 release gate is completed.
