# PL Creators Suite v1.2.2 Validation

## Wave

v1.2.2 — Command Registry, Event Bus, Settings, and Capability Services

## Objective

Provide reusable typed platform contracts for commands, capabilities,
events, settings, and permission-aware service discovery.

## Implemented

### Command Registry

- Typed command definitions
- Searchable registry
- Version metadata
- Deprecation metadata
- Replacement command metadata
- Permission declarations
- Permission-aware execution
- Duplicate and unknown command handling

### Event Bus

- Generic typed event bus
- Typed event envelopes
- Correlation metadata
- Subscribe/unsubscribe
- One-shot subscriptions
- Async emission
- Listener diagnostics and cleanup

Initial event domains:

- project
- asset
- slice
- engine
- task
- terminal
- extension
- AI
- cloud
- collaboration

### Settings

Supported scopes:

- application
- profile
- project
- slice
- language
- extension
- provider

Resolution uses deterministic specificity precedence.

### Capability Services

- Runtime capability contract
- Searchable runtime capability registry
- Status filtering
- Version/deprecation metadata
- Replacement metadata
- Permission declarations

The runtime capability service does not replace the canonical capability
ledger under `docs/capabilities/registry/`. Runtime consumers receive
capability records through the platform service rather than maintaining
another independent capability source of truth.

### Service Discovery

- Shared service registry
- Versioned service descriptors
- Permission declarations
- Permission-aware discovery
- Duplicate and unknown service rejection
- Discovery availability checks
- Deprecation/replacement metadata

### Platform Runtime

`createPlatformRuntime()` composes:

- command registry
- capability registry
- event bus
- settings store
- service registry

This establishes an explicit shared platform composition root and reduces
the need for direct cross-module imports.

## Validation

Required checks:

- `pnpm test:platform-commands`
- `pnpm test:platform-events`
- `pnpm test:platform-settings`
- `pnpm test:platform-services`
- `pnpm test:shell-shortcuts`
- `pnpm test:renderer-architecture`
- `pnpm build:renderer`
- `git diff --check`

## Deferred

This wave does not implement:

- Command Center UI
- command palette UI
- persistent cross-process settings storage
- network event transport
- cloud synchronization
- extension sandboxing
- process-level service isolation

Those belong to later roadmap waves.
