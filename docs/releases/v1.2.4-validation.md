## Safety invariants

1. Recovery data does not overwrite authoritative project data without an explicit restore.
2. Snapshot restore creates a safety backup before destructive changes.
3. Recovery storage remains isolated beneath `.pl-recovery`.
4. `.pl-recovery` and `.pl-index` are excluded from project snapshots.
5. Snapshot and restore paths enforce project-root containment.
6. Named checkpoints are preserved by default retention policy.
7. Corrupt recovery records fail visibly rather than disappearing silently.
8. Existing project migration retains its pre-write manifest backup.
9. Failed imports remain staging-only and do not overwrite installed projects.
10. Shared platform TypeScript is compiled independently from renderer compilation.
