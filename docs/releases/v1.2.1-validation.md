# PL Creators Suite — v1.2.1 Validation

## Milestone

v1.2.1 — Unified Application Shell and Workspace System

## Result

Implemented and validated as the shared shell foundation for the v1.2 platform-development line.

This validation covers the v1.2.1 development wave only. It is not the Public Beta 1.2 release gate, which remains dependent on v1.2.2 through v1.2.6 and the full v1.2 release validation requirements.

## Implemented platform contracts

- Shared application shell regions
- Shared sidebar, top bar, main region, workspace region, bottom-panel region, and status bar
- Persistent shell state
- Workspace switching persistence
- Built-in workspace profiles
- Layout reset behavior
- Copilot and simulation-panel visibility persistence
- Interface zoom state and scalable shell behavior
- Standard and high-contrast shell themes
- Visible keyboard-focus styling
- Reduced-motion baseline behavior
- Shared loading, empty, error, disabled, warning, permission, and destructive-action states
- Shared save/dirty-state indicator
- Shortcut registration
- Shortcut normalization
- Shortcut conflict detection
- Editable-control shortcut protection
- Workspace, zoom, contrast, and reset-layout shortcuts

## Shortcut baseline

- Ctrl+1 — Code
- Ctrl+2 — Docs
- Ctrl+3 — Spreadsheets
- Ctrl+4 — Modeling
- Ctrl+5 — Movie / Animation
- Ctrl+6 — Game
- Ctrl+0 — Reset interface zoom
- Ctrl+Shift+H — Toggle high contrast
- Ctrl+Shift+L — Reset workspace layout

Shortcuts do not execute while normal editable controls have focus unless explicitly permitted by the binding.

## Save-state baseline

The shell status bar derives its unsaved-state indicator from the existing dirty-state signals for Docs, Code, Spreadsheets, Modeling, Movie/Animation, and Game.

A centralized cross-slice saving transaction/progress service is not claimed by this milestone and remains part of later shared-operation/history infrastructure.

## Accessibility baseline

Validated structural support includes:

- visible `:focus-visible` keyboard focus
- high-contrast shell styling
- scalable interface zoom
- reduced-motion handling
- disabled-control presentation
- accessible live-region semantics for common application states
- status semantics for save state

Full v1.2 keyboard-only and common-dialog release validation remains part of the Public Beta 1.2 gate.

## Architecture boundaries

The shortcut registry introduced here is not the v1.2.2 Command Registry.

v1.2.2 will create the searchable, versioned command/capability registry, event bus, layered settings scopes, and permission-aware service discovery. Shell shortcuts may later bind to those command IDs rather than direct callbacks.

## Known limitations

- Shell zoom currently scales the application shell as one interface rather than using per-component density/layout modes.
- Built-in workspace profiles currently primarily select workspace and shared shell state; richer per-profile layouts remain available for later extension.
- Not every historical ad-hoc empty/error surface has been migrated to the new shared components yet.
- Saving progress is not centrally tracked; the current indicator reliably represents dirty versus clean slice state.
- Shortcut remapping UI is not part of v1.2.1.
- Searchable commands and command palette behavior belong to v1.2.2 / later command-center work.
- Full dockable/resizable IDE-style panels are not claimed where a slice does not yet expose those panel types.
- Public Beta 1.2 migration, rollback, installer, Windows, and package validation are not part of this wave closeout.
