# PL Creators Suite v1.1 File Compatibility Baseline

## Purpose

This document records file and project formats explicitly validated during the v1.1 stabilization baseline.

A format marked `validated` is only certified for the behavior listed here. The absence of a format from the validated set does not necessarily mean the application cannot interact with it; it means v1.1.5 has not certified that compatibility.

## Validated Formats

| Scope | Format | Direction | Status |
| --- | --- | --- | --- |
| project | .plproj | import, export, round-trip | validated |
| project | JSON | read, write, round-trip | validated |

| sheets | JSON | fixture-preservation | validated |

| modeling | JSON | fixture-preservation | validated |
| movie | JSON | fixture-preservation | validated |
| game | JSON | fixture-preservation | validated |

## Validation Notes

### project-plproj

Native PL Creators Suite project archive. Archive entries are validated before extraction and project imports use staging.

Validation: scripts/project-format-test.js, scripts/fixture-roundtrip-test.js

### project-manifest-json

Schema-versioned native project manifest.

Validation: scripts/project-format-test.js, scripts/fixture-roundtrip-test.js

### docs-json

Current v1.1 canonical Docs fixture payload. This does not claim external DOCX, PDF, ODT, or Markdown round-trip compatibility.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

### sheets-json

Current v1.1 canonical Sheets fixture payload. This does not claim XLSX, ODS, or CSV round-trip compatibility.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

### code-javascript

JavaScript source content survives native project round-trip. This is not a claim about language tooling completeness.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

### modeling-json

Current v1.1 canonical Modeling scene payload. No OBJ, STL, FBX, glTF, or GLB interoperability is claimed by this baseline.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

### movie-json

Current v1.1 canonical Movie/Animation timeline payload. No external video, audio, or interchange-format round-trip claim is made here.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

### game-json

Current v1.1 canonical Game project payload.

Validation: scripts/fixture-baseline-test.js, scripts/fixture-roundtrip-test.js

## External Formats Not Baselined

The following external formats are intentionally not certified by the v1.1 baseline:

- **docs:** DOCX, PDF, ODT, Markdown — not-baselined
- **sheets:** XLSX, ODS, CSV — not-baselined
- **modeling:** OBJ, STL, FBX, glTF, GLB — not-baselined
- **movie:** MP4, WebM, WAV, MP3 — not-baselined
- **game:** external engine/project formats — not-baselined

## Native Project Archive

The native `.plproj` format is the principal project-level compatibility target for v1.1.

The validation suite exercises project creation, reopen, checksum validation, integrity inspection, export, import, payload preservation, and reopen after import across all six canonical slice fixtures.
