# PL Creators Suite - Architecture Guardrails (v1)

## Non-negotiable
- Offline-first: core features work without internet
- User owns data: project folder or disk are the source of truth
-No forced cloud dependency
- Simple > clever
- Future feature must be scaffolded, not hacked in

## v1 Foundations
- Desktop app shell
- UI + shared component library
- Local backend services
- JSON-RPC boundary between UI and backend
- Logging + export logs
- Minimal plugin scaffold

## Out of scope (v1)
- AR/VR 
- Hardware integration
- Marketplace 
- Collaboration/sync
- Deep performance optimization
