# PL Creators Suite Supported Development Environments

## Purpose

This document defines the supported development and build baseline for the PL Creators Suite v1.1 development line.

## Supported Baseline

| Component | Supported Version |
|---|---:|
| Node.js | 22.12.0 |
| pnpm | 10.31.0 |
| Electron | 41.10.3 |
| electron-builder | 26.15.6 |
| TypeScript | 5.9.3 |
| Vite | 7.3.6 |
| React | 19.2.3 |
| React DOM | 19.2.3 |
| Three.js | 0.184.0 |

## Supported Operating Systems

### Linux

Primary development environment:

- Pop!_OS
- Ubuntu-compatible x64 distributions
- AppImage packaging target

### Windows

Supported validation environment:

- Windows 11 x64
- NSIS Setup.exe packaging target
